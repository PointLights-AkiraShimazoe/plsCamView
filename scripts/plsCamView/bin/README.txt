Place ffmpeg.exe here to enable MP4 export without any PATH setup.
  e.g. https://www.gyan.dev/ffmpeg/builds/  (ffmpeg-release-essentials.zip -> bin/ffmpeg.exe)
ffmpeg is licensed under LGPL/GPL; plsCamView only launches it as an external process.

MP4 出力を使うには、このフォルダに ffmpeg.exe を置いてください（PATH の設定は不要になります）。
