# 複数カメラ Playblast（Multi）

Multi を ON にして各ビュー上部の Playblast 対象（● PLAYBLAST）を複数選び、ツール内の実行ボタンから順次撮影します。対象は最大 4 ビューです。Maya 標準メニュー／外部ツールを Force Playblast Target で固定する経路は、最後に追加した主対象 1 つです。

| 合成 | 個別保持 | 出力 |
|---|---|---|
| ON | ON（既定） | カメラごとの出力と `_Multi.mp4` |
| ON | OFF | `_Multi.mp4`。個別撮影データは合成成功後に整理 |
| OFF（既定） | 非表示 | カメラごとの出力 |

Multi は既定 OFF で、OFF 時は対象を 1 つだけ選べます。ON 時だけ合成スイッチを表示し、合成 ON 時だけ個別保持を表示します。保存済みの設定は保全します。

## 出力名

出力欄は共通の名前として使います。`shot_review.mp4` を指定して front / side を選ぶと `shot_review_front.mp4`、`shot_review_side.mp4`、`shot_review_Multi.mp4` です。出力欄が空なら現在のシーン名を共通名とします。

カメラ短名が重複すると、該当するカメラだけ namespace を使って区別します（入れ子 namespace の `:` は Windows で使用できないため `_` にします）。namespace でも区別できない対象、namespace なしの同名カメラ、同じカメラの重複選択は撮影前に止めます。

## 合成

合成の全体サイズは出力設定の幅・高さです。表示中の対象ビューの位置・比率に合わせ、各映像は縦横比を保って収め、余白を黒にします。選択範囲の外周は詰め、対象間の空間は保持します。ポップアウトを合成する場合は、表示し、ウィンドウ同士が重ならないようにします。幅・高さは偶数です。合成は MP4、個別は選択した出力形式です。音声は最初の映像のものを 1 本だけ使用します。

## 保護と取消

既存出力があれば別の共通名を指定してください。上書きしません。取消・撮影失敗・合成失敗の場合、出力フォルダー内の `.plsMulti-…` に途中データを残し、場所をエラーへ表示します。1 カメラの撮影中はその処理が戻るまで取消が反映されない場合があります。

1 ビューだけを対象にした場合は従来の単体出力です。複数対象は開始時のカメラ、配置、フレーム範囲を固定して順次出力し、終了時に開始フレームとフォーカスを戻します。
